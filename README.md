# NeuroPulse Companion

Patient companion app for **NeuroPulse**, a concept AI-powered closed-loop sub-clavicular neural implant (HOSA Medical Innovation demo).

**▶ 1-minute demo** (top bar) runs a guided 60-second walkthrough: it switches tabs, triggers a tremor spike, and shows a script to read along. Space pauses, ←/→ skip, Esc exits.

The demo follows one patient with Parkinson's disease.

| Tab | Core features |
| --- | --- |
| **Brain & Implant** | Live STN beta-wave monitor, "Simulate tremor spike" (Sense → Detect → Decide → Treat → Steady), optional technical details, and implant battery, medicine reservoir and refill countdown. |
| **Meals** | MIND diet with protein timing around levodopa, key nutrient (tyrosine), and a weekly grocery & prep list. |
| **Exercise & Sleep** | Best time to exercise from NeuroPulse data, compact guided LSVT BIG-style exercises with a timer, and sleep linked to brain stability. |

All data is simulated. Not a medical device.

```bash
npm install
npm run dev
```
